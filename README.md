# HIIT Cycling

A small indoor cycling timer I built because I wanted to do ~30-minute HIIT rides at my gym using my own music instead of taking a class.

I built the app with Claude as a non-technical operator and deployed it on Netlify.

## What it does

- Beginner, intermediate, and advanced HIIT presets
- Timed sprint and recovery intervals
- Countdown beeps for phase changes
- Optional music import
- Works alongside music already playing in the background

The intermediate workout is:

5 min warm-up → 30 sec sprint / 60 sec recovery × 10 → 3 min cool-down

## Live demo

https://hiitindoorcycling.netlify.app

## Why I built it

I wanted a very specific indoor cycling workflow and couldn't find an existing timer that worked exactly the way I wanted, so I used Claude to build one.

I'm a marketer, not a developer. This is part of me experimenting with using AI to turn small ideas into working products.
